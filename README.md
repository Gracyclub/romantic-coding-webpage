# ✨ Two Souls, One Universe ✨

> *"Coding isn't romantic? Really? 💖"*

An interactive, romantic web animation created using **HTML5 Canvas**, **CSS3**, and **JavaScript**. Drag the two glowing souls together in a cosmic space to merge them into a glowing heart and reveal a heartfelt note.

---

## 🌟 Features

- 🌌 **Cosmic Ambient Background:** Beautiful twinkling stars and glowing particles.
- 💫 **Interactive Soul Dragging:** Smooth physics-based dragging animation.
- ❤️ **Heart Particle Explosion:** Vibrant neon heart effect upon merging.
- 💌 **Romantic Modal Popup:** Elegant pop-up message for your special someone.
- 📱 **Fully Responsive:** Works smoothly across both desktop and mobile screens.

- **HTML5** & **HTML5 Canvas** (Particle rendering & physics)

- **JavaScript (Vanilla)** (Interactive drag-and-drop & logic)

2. Navigate to the directory:
 ```bash
cd two-souls-one-universe
```
